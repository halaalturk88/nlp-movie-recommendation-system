# Dataset setup

This application requires the **TMDB 5000 Movie Dataset** and associated credits data. Obtain the two files from an authorized dataset source (commonly distributed as “TMDB 5000 Movie Dataset” on Kaggle), and check the dataset terms before redistribution.

Place these files in this directory:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

The application will not start without both files. They are intentionally not committed in this portfolio repository.
